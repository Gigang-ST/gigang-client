# [v2.3.0] 겨울 10K PB 클래스 · 개인 일정 외 18건

> 게시 유형: 업데이트  
> 작성일: 2026-10-22

---

지난 v2.2.0 이후 한 달 동안 바뀐 것들을 모았습니다.
가장 큰 변화는 두 가지입니다. **겨울 10K PB 클래스가 프로젝트 탭에 열렸고**, **일정 탭에 나만 보는 개인 일정을 넣을 수 있습니다.**

## 겨울 10K PB 클래스

프로젝트 탭에서 **겨울 10K PB 클래스**에 참가할 수 있습니다. 마일리지런이 각자 뛴 거리로 환급했다면, PB 클래스는 **공식훈련 모임에 나온 횟수**로 보증금을 돌려받습니다.

- 공식훈련 12회와 10K 측정 1회, 모두 **13회**입니다. 주로 **반포종합운동장**에서 진행합니다.
- **9회 이상 출석하면 보증금을 전액 환급**받습니다. 출석은 앱의 모임 참석 기록으로 자동 집계됩니다.
- **참가비**는 일반 **1만 원**, 마일리지런 참가자는 **5천 원**입니다.
- 신청 → 입금 확인 → 참가 순서로 진행됩니다.

| 탭 | 볼 수 있는 것 |
|---|---|
| 내 현황 | 내 출석(`n / 13`) · 환급 예상액 · 13칸 회차 띠 · 내 팀 · 내 점수 |
| 훈련 | 주차별 훈련표와 내 훈련 안내 |
| 점수판 | 게임팀 순위 · 10K 예상기록 트랙 · 주차별 누적 출석과 팀 점수 그래프 |
| 안내 | 규칙과 일정 |

- **훈련팀은 자동으로 정해집니다.** 내 목표와 최근 기록을 보고 맞는 팀에 들어갑니다.
- **점수판은 참가하지 않아도 구경할 수 있습니다.**
- 진행 중인 프로젝트가 여럿이면 맨 위에서 **마일리지런 ↔ PB 클래스를 골라 볼 수 있습니다.**
- 끝난 프로젝트는 지우지 않고, 프로젝트 탭 맨 아래 **[지난 프로젝트]**에서 다시 볼 수 있습니다.

## 나만 보는 개인 일정

일정 탭(달력·리스트)에 **나만 보이는 개인 일정**을 넣을 수 있습니다.

- 일정 탭 **+ 버튼 → 🔒 개인 일정**에서 제목·날짜·시간·메모를 적습니다. 시간을 비우면 **종일** 일정입니다.
- 개인 일정은 **시안색**으로 표시되고, **⭐ 내 일정** 필터에도 함께 나옵니다.
- 일정을 누르면 **복제 · 수정 · 삭제**를 할 수 있습니다. 복제하면 날짜만 비운 채 나머지가 채워집니다.
- 새로 만들 때 **[최근 불러오기]**로 전에 넣은 일정 내용을 가져올 수 있습니다.

> 다른 크루원에게는 **절대 보이지 않습니다.** 주간 일정 공유에도 실리지 않습니다.

**그 밖의 변경**

- **마일리지런 시즌 돌아보기**: 시즌이 끝나면 달린 거리·사진·한마디·부문별 상을 한눈에 훑는 화면이 열립니다. 시즌이 끝나고 30일 동안은 기강이야기 맨 앞 칸에서 바로 들어갈 수 있습니다.
- **단톡방에 알림**: 모임 공유 창 맨 위 버튼으로 모임 공지를 단톡방에 **한 번 더** 올릴 수 있습니다. 크루원 누구나 남의 모임도 올릴 수 있습니다(지난 모임 제외).
- 모임을 등록하면 단톡방에 자동으로 공지되므로, 등록 직후의 **"공유해 주세요" 안내는 없앴습니다.**
- **모임 취소 기록**: [프로필] 최근활동에 내 모임 취소 횟수가 보입니다. **본인에게만** 보입니다.
- **탈퇴 사유 안내**: 탈퇴 처리된 경우 사유를 본인이 볼 수 있고, 그 화면에서 **[재가입 요청하기]**를 누를 수 있습니다.
- **다시 가입**: 삭제된 회원은 다시 가입하면 **승인을 기다리지 않고 바로** 돌아옵니다. 예전 기록과 칭호도 그대로 이어집니다.
- 비활성·탈퇴 상태가 풀리면 **알림**으로 알려 드립니다.
- **대회 종목이 긴 종목부터** 정렬됩니다(예: 100K → 50K → 20K).
- 알림 목록을 읽던 중에 새 알림이 와도 **읽던 자리가 그대로** 유지됩니다.
- **마런정복자 칭호** 조건이 "시즌 기간의 모든 달 목표 달성"으로 바뀌었습니다.
- 탭바 위를 걸어다니던 **접속자 얼굴은 잠시 쉬어 갑니다.** 서버 부담을 줄인 뒤 다시 돌아옵니다.

**버그 수정**

- 철인3종 기록이 기강의 전당 **마라톤 풀코스 칸에 섞여 들어가던** 문제
- 마일리지런 기록을 **수정해서 목표를 채웠을 때 칭호가 안 붙던** 문제
- 모임을 등록한 직후 상세 화면에서 **작성자 버튼(수정 등)이 안 보이던** 문제
- 게시글과 게시판 사이에서 **뒤로가기가 계속 반복되던** 문제
- 기록이 많아지면 **일부 목록·집계가 빠지던** 문제
- 서버 장애가 끝난 뒤에도 **홈 화면이 한동안 비어 있던** 문제
- **10월 22일 새벽 앱이 열리지 않던** 문제(서버 사용량 초과). 원인을 고쳐 다시 일어나지 않도록 했습니다.

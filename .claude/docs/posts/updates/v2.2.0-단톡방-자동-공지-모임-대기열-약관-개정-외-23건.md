## 모임을 만들면 단톡방에 자동 공지

이제 **공유하기를 누르지 않아도** 크루 단톡방에 공지가 올라갑니다.

| 언제 | 단톡방에 올라가는 내용 |
|---|---|
| 모임 등록 | 🏃‍♂️ 같이 뛰어요! — 일시·장소·개설자 + 참여 링크 |
| 일시·장소 변경 | 📢 모임 일시·장소가 변경됐어요 — 바뀐 내용 + 링크 |
| 모임 취소 | ❌ 모임이 취소됐어요 — 제목·일시·장소 |

## 모임 대기열

**정원이 차도 대기 신청을 할 수 있습니다.** 누가 취소하면 가장 먼저 기다린 사람이 **자동으로 참석자가 되고 알림을 받습니다.**

| 내 상태 | 버튼 |
|---|---|
| 자리 있음 | 참석하기 |
| 참석 중 | 참석 취소 |
| 정원 마감 | **대기 신청** (현재 N명 대기 중) |
| 대기 중 | **대기 취소** (대기 N번) |

- 모임 상세 창에서 **대기 명단과 내 순번**을 볼 수 있습니다.
- 참석을 취소했다가 다시 신청하면 **대기열 맨 뒤**로 갑니다.
- 대기를 걸면 자리가 났을 때 **확인 없이 바로 참석 처리**됩니다. 못 가게 되면 꼭 미리 대기를 취소해 주세요.

**모임 시작 2시간 전부터는 선착순입니다.**

- 이때는 자리가 나도 자동으로 참석되지 않습니다. 대신 대기자 전원에게 **빈 자리 알림**이 가고, **먼저 누른 사람**이 참석합니다.
- 버튼도 `빈 자리 알림 요청`으로 바뀝니다.

> 모임 직전에 알림을 못 본 대기 1번 때문에 자리가 빈 채로 시작되는 걸 막기 위해서입니다.

## 약관 개정 (2026-09-30 시행)

이용약관·개인정보 처리방침·운영정책이 바뀌었습니다. [더보기] 맨 아래에서 전문을 볼 수 있습니다.

- **가입 자격**: 1986년생부터 성인까지 가입할 수 있습니다.
- **기록·프로필 공개**: 이름·프로필 사진·대회 기록 등은 기강 앱에 공개되며, 로그인하지 않은 방문자도 볼 수 있습니다.
- **사진**: 모임 사진과 올린 게시물은 크루 공식 인스타그램 등에 게시될 수 있습니다. 원하지 않으면 운영진에게 요청해 주세요. 삭제해 드립니다.
- **제재·비활성**: 제재 전에는 경고하고 소명할 기회를 드립니다. 본인이 요청하면 비활성으로 바꿀 수 있습니다.
- **개인정보**: 수집 항목과 위탁·국외 이전(Supabase 일본, Google 미국) 내용을 실제에 맞게 보완했습니다.

---

**그 밖의 변경**

- **모임 등록**: 장소가 필수가 됐고, 등록 전에 제목·일시·장소를 한 번 더 확인합니다. 종료일시는 시작 + 2시간이 미리 채워집니다.
- **모임 참여조건·승인제**: 모임을 만들 때 "최근 N개월 M회 이상 참석" 조건이나 운영진 승인을 켤 수 있습니다.
- **기강의 전당(랭킹탭)**: 종목별 1위가 맨 위에 올라가고, 내 순위와 1위와의 격차가 보입니다. 크루 가입 전 기록은 랭킹에 오르지 않습니다.
- **칭호**: 신규 25종이 추가됐습니다. 따면 알림이 오고, [프로필] → 칭호의 획득 이력에서 볼 수 있습니다.
- **더보기(☰)**: 맨 위에서 오픈채팅 비밀번호를 다시 볼 수 있습니다.
- **접속자 얼굴**: 이제 모든 탭에서 탭바 위를 걸어다닙니다.
- **캘린더 주 시작 요일**을 일요일·월요일 중 고를 수 있습니다. ([더보기] → 주 시작 요일)
- 프로필탭 얼굴의 **카메라 버튼**으로 프로필 사진을 바로 바꿀 수 있습니다.
- 연동한 **UTMB를 수정·해제·갱신**할 수 있습니다.
- 깅스타그램 사진에 **댓글 수(💬N)**가 표시됩니다.
- **내가 등록한 대회는 내가 직접 수정**할 수 있습니다.
- 비활성 상태일 때 **막힌 이유**를 함께 보여 줍니다.
- PC 브라우저에서는 화면이 **폰 폭으로 모여** 보입니다.
- 다른 사람이 단 댓글은 **다시 열면** 보입니다. 내 댓글은 바로 보입니다.
- 앱이 전반적으로 빨라졌습니다.

**버그 수정**

- 일정 리스트뷰에서 **특정 달 일정이 통째로 안 보이던** 문제
- 일정탭에서 **대회 참가 수정·취소가 안 되던** 문제
- 대회를 수정하면 **참가자들이 고른 종목이 사라지던** 문제
- 안드로이드에서 사진을 고를 때 **갤러리가 안 뜨던** 문제
- 링크로 바로 들어온 화면에서 **뒤로가기가 안 되던** 문제
- 마일리지런 **환급 예정액이 기록을 저장해도 바로 바뀌지 않거나, 일부 기록이 빠진 채 계산되던** 문제
- 참여 감면이 **한 달 회비보다 많이 잡히던** 문제
- 10K 칭호가 남녀 구분 없이 매겨지던 문제

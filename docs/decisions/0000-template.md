- 상태: 승인 | 대체됨 (ADR-MMMM)
- 날짜: YYYY-MM-DD
- 결정자: @… (백필이면 "기록 없음 — 출처 PR #…")
- 대체: 없음 | ADR-NNNN

## 맥락

무엇이 문제였고 왜 그때 정해야 했는가. 숫자·실측이 있으면 출처와 함께.

## 결정

무엇으로 정했는가. 한두 문단으로 단정적으로. 항목이 여럿이면 번호를 매긴다(다른 ADR이 "ADR-NNNN 결정 2"로 가리킬 수 있게).

# ADR-0001: 결정은 `docs/decisions/`에 ADR로 남기고, 기능 PR 안에서 같이 쓴다

- 상태: 승인
- 날짜: 2026-10-29
- 결정자: @LHG4650
- 대체: 없음

## 맥락

이 저장소의 결정은 **본문 속에 섞여 있다.**

- `DESIGN.md`(1,301줄)는 토큰·컴포넌트 같은 참조 내용 사이에 "한때 X였다가 Y로 바꿨다"류 결정 이력이
  29군데 섞여 있다(2026-10-29 실측). `AGENTS.md`(196줄)도 정책 결정의 이유를 본문에 품고 있다.
- 두 파일 모두 `CLAUDE.md`가 통째로 불러와 **에이전트 세션마다 컨텍스트에 실린다.** 이유 문단이 늘수록
  매 세션 비용이 는다.
- 기능 설계 문서가 `docs/superpowers/specs/`(24개)·`docs/design/`(17개)에 있고, 그 안의 "결정" 표는
  기능마다 흩어져 있다. **"이미 정한 건가"를 한 번에 찾을 목록이 없고**, 결정이 뒤집혀도 옛 결정과
  새 결정의 관계가 남지 않는다.
- 같은 논의가 돌아온다. `DESIGN.md`의 빨간 점 규칙은 본문에 "반복해서 다시 논의되는 주제라 이유를
  남긴다"고 적고 있다.

흔히 쓰는 ADR(Architecture Decision Record) 형식을 가져오되, 이 저장소의 흐름에 맞게 줄인다.

## 결정

1. **결정은 `docs/decisions/NNNN-제목.md`에 ADR로 남긴다.** 템플릿은 맥락·결정·고려한 대안·결과 네 칸
   ([0000-template.md](0000-template.md)). 목록은 [README.md](README.md) 표 하나.
2. **ADR을 쓰는 결정**: 되돌리기 비싼 것(데이터 모델·마이그레이션), 외부 서비스·과금 구조, 운영 정책,
   같은 얘기가 두 번 나온 것. 사소한 구현·UI 선택은 쓰지 않는다.
3. **결정을 낳은 기능 PR 안에서 같이 쓰고, 상태는 처음부터 `승인`이다.** 결정 이슈 → ADR PR → 상대 승인
   단계는 두지 않는다.
4. **승인된 ADR 본문은 고치지 않는다.** 바꾸려면 새 ADR로 대체하고 옛 ADR은 상태만 `대체됨`으로 바꾼다.
5. **자리를 나눈다**: 규약은 `AGENTS.md`, 화면 규격은 `DESIGN.md`, 함정은 `KNOWLEDGE.md`, 기능 설계는
   설계 문서, "왜 A인가"는 ADR. 설계 문서 안의 결정 표는 그대로 두고 ADR이 링크한다.
6. **기존 결정은 한꺼번에 옮기지 않는다.** 이미 값을 치른 결정(0002~0005)부터 넣고, 나머지는 그 주제를
   다시 건드리는 PR에서 옮긴다.

## 고려한 대안

- **결정 이슈에서 논의하고, 상대가 ADR PR을 승인(Approve)하면 그 머지를 합의로 친다** — 택하지 않았다. 이 저장소는 dev PR도
  리뷰 승인 없이 관리자 권한으로 머지하는 흐름이라(#603~#611), 승인 단계를 두면 형식만 남는다.
- **지금처럼 DESIGN.md·AGENTS.md 본문에 이유를 계속 적는다** — 택하지 않았다. 매 세션 실리는 파일이
  계속 커지고, 참조 내용과 결정 이력이 섞여 둘 다 찾기 어렵다.
- **외부 지식 위키(knowledge-hub)에 둔다** — 택하지 않았다. 저장소 밖이라 다른 팀원·다른 도구(Codex·Cursor)가
  같은 것을 못 본다. 결정은 코드와 같이 리뷰되고 같이 버전이 붙어야 한다.
- **설계 문서 안 결정 표로 충분하다** — 택하지 않았다. 기능별로 흩어져 목록이 없고 대체 관계를 추적하지 못한다.

## 결과

- 쉬워지는 것
  - "이거 정한 적 있나"를 README 표 하나로 확인한다.
  - 결정이 뒤집혀도 옛 이유가 남는다(대체 관계).
- 어려워지는 것
  - 문서를 둘 자리가 하나 늘었다. 위 결정 5의 구분을 지키지 않으면 오히려 더 흩어진다.
  - 백필한 ADR은 당시 대안이 남아 있지 않은 경우가 많다 — 그렇다고 적는다.
- 후속 작업
  - `DESIGN.md`·`AGENTS.md`의 "왜" 문단을 ADR로 옮기고 본문은 포인터로 줄인다(별도 PR — 범위가 크다).
  - `AGENTS.md`에 "결정과 다르게 하려면 새 ADR부터" 포인터를 둔다(이 PR).

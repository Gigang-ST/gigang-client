# ADR-0003: 기강 포인트는 본인 프로필탭에서만 숫자로 보이고, 적립 규칙은 어디에도 적지 않는다

- 상태: 승인
- 날짜: 2026-07-29
- 결정자: 기록 없음 — 출처 PR #466 · `docs/design/2026-07-04-기강포인트제도.md`
- 대체: 없음 (제도 설계 §1 「노출 0」을 부분 해제한다)

## 맥락

기강 포인트(`pt_txn_hist` 원장)는 2026-07-04 **히든 운영**으로 시작했다 — 적립은 실제로 돌지만 UI 어디에도
표시하지 않고, 추후 공개를 전제로 처음부터 감사 가능한 원장을 쌓는다(제도 설계 §1·§7).

프로필탭을 프로필 카드 편집판으로 개편하면서(#466, 2026-07-30 머지) 본인 화면에만 총 획득 포인트를 띄우게 됐다.
문제는 그 숫자가 **남에게 보이는 순간 사실상 공개 랭킹이 된다**는 점이다.

## 결정

1. **총 획득 포인트는 본인 프로필탭에서만 숫자로 보인다** — 최근활동 헤더 우측 `N P` + `HelpTip`.
2. **그 밖에는 절대 노출하지 않는다** — 남의 프로필 카드(공개판 팝업 포함, 내 카드여도), 랭킹, 전광판.
3. **적립 규칙·배점은 화면에 적지 않는다.** `HelpTip` 은 "모임 참석·대회 출전·기록 등록으로 쌓여요" 한 줄까지.
4. **화면 이름은 "활동량"이다** — 전광판 활동량 랭킹은 제도 이름(포인트)을 쓰지 않는다.
5. **PB 클래스 게임 점수는 다른 제도다** — "점수"라 부르고 공개한다. "포인트"라고 쓰면 히든 지표가 새 나간
   것처럼 읽히고, 반대로 기강 포인트를 그 화면에 섞으면 공개 랭킹이 된다.

## 고려한 대안

백필이라 당시 검토한 대안의 기록이 남아 있지 않다. 부분 해제를 택한 이유도 PR #466 에는 "본인 프로필탭에서만
숫자 노출, 적립 규칙·배점은 계속 비공개"라는 범위만 적혀 있다.

## 결과

- 쉬워지는 것: 본인은 자기 활동이 쌓이는 걸 본다. 공개 전환(제도 설계 §8) 때 숫자가 이미 채워져 있다.
- 어려워지는 것: 프로필 카드는 한 컴포넌트가 편집판·공개판을 다 그려서, 편집판에만 있는 포인트가 공개판으로
  새지 않게 늘 지켜야 한다.
- 이 결정을 지키는 곳: `components/members/__tests__/member-card-detail-render.test.ts`(공개판에 포인트가 없음을
  마크업으로 못박는다), `AGENTS.md` 「기강 포인트」, `DESIGN.md` 「프로필탭에서만 보이는 것」.

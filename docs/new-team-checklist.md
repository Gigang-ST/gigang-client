# 새 팀 추가 체크리스트

울산(모보브)을 붙이면서 실제로 거친 단계를 정리했다(2026-11-10). 세 번째 팀부터는 이 문서만 따라가면 된다.
팀마다 다른 것은 **팀 설정(DB)·팀 파일 표(코드)·팀 전용 말투 표(코드)** 세 곳에 모여 있고, 화면 코드에는 팀 이름이 박혀 있지 않다
(§AGENTS.md 「화면 문구에 팀 이름을 박지 않는다」).

아래 예시는 팀 코드 `busan`. 팀 코드는 영문 소문자이고, 주소·파일 폴더·코드 표의 키로 같이 쓰인다.

## 1. 코드 — 팀 등록 (배포 필요)

| 할 일 | 파일 |
|---|---|
| 팀 UUID 한 줄. dev·prd 에 **같은 값**으로 넣는다 | `lib/constants/gigang-team.ts` 의 `TEAM_ID_BY_CD` |
| 주소 → 팀(운영·dev·로컬), 팀 → 정식 주소 | `lib/team-host.ts` 의 `TEAM_CD_BY_HOST` · `CANONICAL_HOST_BY_TEAM` |
| 팀 행 마이그레이션(`team_mst`) | 예: `supabase/migrations/20261109110000_seed_team_ulsan.sql` 을 본떠 새 파일 |
| 회귀 테스트에 새 주소 | `lib/__tests__/team-host.test.ts` |

주소 표에 없는 주소는 **팀이 없는 것**으로 보고 404 를 낸다(오타 주소로 들어와 기강 데이터에 쓰는 사고를 막는다).

## 2. 파일 — 로고·아이콘·썸네일 (배포 필요)

`public/teams/<팀코드>/` 에 아래 파일을 넣고, `lib/team-site.ts` 의 `TEAM_SITE` 에 한 줄 더한다(울산 줄을 그대로 본뜬다).
**표에 없는 칸은 안 내보낸다** — 다른 팀 그림으로 물러나지 않는다.

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `og.png` | 1200×630 | 카톡 등 링크 미리보기 썸네일 |
| `logo.png` | 투명 배경 원본 | 구조화 데이터(네이버) |
| `favicon-16x16.png` · `favicon-32x32.png` · `favicon-96x96.png` | | 브라우저 탭 아이콘(16·32 는 글자 없이 마크만) |
| `apple-icon-180x180.png` | | iOS 홈 화면 |
| `android-icon-72x72` · `96` · `144` · `192` · `icon-512x512.png` | | 안드로이드 설치 앱 |
| `ms-icon-70x70` · `150` · `310.png` + `browserconfig.xml` | | 윈도 타일 |
| `notification-icon.png` (컬러) · `notification-badge.png` (흰 실루엣 + 투명, 96×96) | | 푸시 알림 |
| `manifest.webmanifest` | | 설치 앱 이름·아이콘 — **앱 이름이 여기 적힌다**(팀 설정 크루 이름을 따르지 않는다. 브라우저가 화면마다 받아 가는 파일이라 정적 파일로 둔다) |

`/teams/` 폴더는 proxy(로그인 확인)를 타지 않는다 — 쿠키 없이 오는 봇·manifest 요청이 로그인으로 튕기지 않게(`proxy.ts` matcher).

`TEAM_SITE` 에서 같이 정하는 것: 구조화 데이터의 정식 이름·다른 이름·종목·지역(`organization`), AI 검색용 소개문(`llmsTxt`,
없으면 그 주소의 `/llms.txt` 는 404), 네이버 소유확인 코드(네이버에 그 주소를 등록했을 때만).

## 3. 바깥 설정 (콘솔)

- **Vercel 도메인**: 운영 프로젝트 `gigang-client` 에 운영 주소, dev 프로젝트 `gigang-client-dev` 에 dev 주소.
- **Supabase Redirect URLs**(dev·prd 각각): `https://<주소>/**` 꼴로 넣는다. `/auth/callback` 정확한 주소로 넣으면
  앱이 붙이는 `?next=…` 때문에 안 걸려 **로그인이 기강 주소로 튕긴다**(울산에서 실제로 겪었다).

## 4. 팀 설정 — 관리자 「팀 설정」 화면 (배포 없음)

새 팀 주소로 로그인한 관리자가 채운다. **비어 있으면 그 칸이 안 보이거나 중립어로 나온다** — 기강 값으로 물러나지 않는다.

| 묶음 | 키 | 비면 |
|---|---|---|
| 기본 설정 | 크루 이름(`brand.name`) | 팀 기본 이름(5번 말투 표), 없으면 「크루」 |
| 기본 설정 | 회원 호칭(`brand.member_noun`) | 팀 기본 호칭(5번 말투 표), 없으면 「크루원」 |
| 기본 설정 | 슬로건 · 창설일 · 워드마크 | 그 줄을 안 그린다 |
| 검색·공유 | 홈 제목 · 탭 제목 뒤 말 · 설명 | 크루 이름 / 크루 이름 / 슬로건 |
| 크루 안내 | 팀 채널 · 오픈채팅 비밀번호 · 모임 계좌 | 안 보인다 |
| 운영 · 기능 | 카톡 공지방 · 전당 종목 · 모임 기본 종목 · 회비/칭호 켜기 | 기본 동작 |

크루 이름을 정하면 화면 곳곳(「○○에 합류」「○○의 전당」「○○이야기」, 조사 포함)이 저절로 따라온다.
**첫 owner 는 SQL 로 세운다**(화면에서 못 정한다) — `docs/migrations/multi-team-prd-rollout.md` 「배포 후 정리」의 SQL.

## 5. 선택 — 팀 기본 이름·팀만의 말투 (배포 필요)

`lib/team-copy.ts` 의 `TEAM_VOICE` 에 그 팀 줄을 더하면:
- **팀 기본 이름**(`crewName`·`memberNoun`·`wordmark`) — 팀 설정이 비었거나 **못 읽었을 때** 쓴다. 말장난을 넣는 팀이면
  **꼭 같이 넣는다** — 안 넣으면 설정 조회가 실패한 순간 이름은 「크루」인데 말장난은 그 팀 것이라 한 화면에 섞인다.
- **말장난** — 기강의 「기강이 빠졌군. 알림 켜라!」「깅스타그램」처럼 팀 이름 뜻에 기댄 문구. 없으면 중립 문구(「알림을 켜 두세요」「갤러리」).
- **지면 검색 설명**(`pageDescriptions`) — 검색에 걸리게 지역·종목을 넣어 다듬은 문장. 없으면 크루 이름으로 만든 중립 문장.

 글자 수 제한이 있는 자리(리드 18자 근처,
헤더 224px)라 화면에서 확인하고 넣는다. 회귀 테스트 `lib/__tests__/team-copy.test.ts`.

# 노티봇 Iris 전환 시 기강 연동

기강은 `lib/kakao/notify.ts` 한 곳에서 `@kakao-bot/sdk`의 `sendMessage`를 사용한다.
Iris의 폰 주소·토큰이나 카카오 내부 방 ID를 기강에 넣지 않는다. 허브가 전송 계층을 맡는다.

- `KAKAO_ROOM_ID`는 허브 콘솔에서 복사한 방 UUID다. 기존 `KAKAO_ROOM`보다 우선한다.
- 방 UUID로 요청했으면 성공·실패 이력 모두 UUID를 보존한다. 다시 보내기가 방 이름 변경이나 동명 방에 영향을 받지 않도록 한다.
- 요청 전에 멱등 키를 만들어 전송하고, 응답이 유실돼도 이력에 같은 키를 남긴다.
- 자동 재시도는 하지 않는다. 관리자의 다시 보내기도 저장된 키를 사용하며, 키가 없는 과거 이력은 허브에서 중복 여부를 확인하도록 막는다.
- 허브 `202`는 접수 성공이다. 카카오톡 수신자에게 도착했음을 증명하지 않으므로 관리 화면은 `접수`로 표시한다. DB의 기존 `success` 값은 허브 접수 의미로 유지한다.

`@kakao-bot/sdk@0.3.0`을 `package.json`과 `pnpm-lock.yaml`에 고정한다.
이 프로젝트는 Iris 수신 웹훅을 처리하지 않아 신규 수신 이벤트 타입이나 이미지 본문을 소비할 필요가 없다.

검증: 실제 메시지를 보내지 않고 SDK HTTP 요청 모킹으로 고정 방 ID, 응답 유실 시 멱등 키 보존, 수동 재시도 방어를 확인한다.
